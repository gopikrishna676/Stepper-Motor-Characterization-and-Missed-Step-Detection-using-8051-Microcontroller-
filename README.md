# Stepper-Motor-Characterization-and-Missed-Step-Detection-using-8051-Microcontroller-
Developed an 8051 microcontroller-based stepper motor monitoring and control system with real-time speed adjustment and feedback using an encoder. Implemented push-button controls for dynamic speed variation and integrated missed-step detection to improve motion accuracy and reliability.

# Stepper Motor Characterization System

This project focuses on characterization and monitoring of a stepper motor using encoder feedback and Arduino-based control.

## Features
- Stepper motor control
- Speed adjustment using push buttons
- Rotary encoder feedback
- Missed step detection

## Technologies Used
- Arduino
- Embedded C/C++
- Stepper Motor Driver
- Rotary Encoder
